# Job Portal Management System

## Description
A full-stack Job Portal web application developed using Java, Spring Boot, Thymeleaf, HTML, CSS, and MySQL. The system allows students to search and apply for jobs while employers can post jobs and manage applications.

---

## Features
- User Registration and Login
- Job Search and Job Application
- Resume Upload
- Employer Job Posting
- Application Status Tracking
- Admin Module
- Email Notifications

---

## Technologies Used
- Java
- Spring Boot
- Thymeleaf
- HTML
- CSS
- MySQL
- Spring Data JPA

---

## Modules

### Student Module
- Register and Login
- Search Jobs
- Apply for Jobs
- Upload Resume
- Track Application Status

### Employer Module
- Post Jobs
- View Applications
- Manage Job Listings

### Admin Module
- Manage Users
- Manage Job Posts
- Monitor System

---

## Project Architecture
The project follows a three-tier architecture:
1. Frontend Layer
2. Backend Layer
3. Database Layer
